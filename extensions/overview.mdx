## How Extensions Work

Extensions are packaged as TypeScript modules that register tools, commands, and hooks with the GSD 2 runtime. They provide:

- **Tools**: Functions the agent can call during task execution
- **Commands**: Slash commands users can invoke in the CLI
- **Shortcuts**: Keyboard shortcuts for quick actions
- **Hooks**: Event handlers for session lifecycle events

## Extension Architecture

All built-in extensions follow a consistent pattern:

```typescript
import type { ExtensionAPI } from "@gsd/pi-coding-agent";

export default function (pi: ExtensionAPI) {
  // Register tools
  pi.registerTool({
    name: "tool_name",
    description: "What the tool does",
    parameters: Type.Object({ /* ... */ }),
    execute: async (toolCallId, params, signal, onUpdate, ctx) => {
      // Tool implementation
      return {
        content: [{ type: "text", text: "Result" }],
        details: { /* structured metadata */ }
      };
    }
  });

  // Register commands
  pi.registerCommand("command", {
    description: "Command description",
    handler: async (args, ctx) => {
      // Command implementation
    }
  });

  // Register lifecycle hooks
  pi.on("session_start", async (event, ctx) => {
    // Hook implementation
  });
}
```

## Environment Variables

Some extensions require API keys or configuration:

| Extension | Variable | Required | Purpose |
|-----------|----------|----------|----------|
| Search the Web | `BRAVE_API_KEY` | Optional* | Brave Search API access |
| Search the Web | `JINA_API_KEY` | Optional | Higher rate limits for page extraction |
| Context7 | `CONTEXT7_API_KEY` | Optional | Higher rate limits for docs |
| Browser Tools | `BROWSER_PATH` | Optional | Custom browser executable |

<Note>
  *`BRAVE_API_KEY` is optional when using Anthropic models, which have built-in web search.
</Note>
