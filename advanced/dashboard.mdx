# Dashboard Overlay

The GSD dashboard provides real-time visibility into auto-mode execution: current unit, completed units, milestone/slice/task breakdown, cost tracking, and activity logs.

## Opening the Dashboard

**Keyboard shortcut:**
- Press `Ctrl+Alt+G` during auto-mode

**Command:**
```bash
/gsd status
```

The dashboard overlays the entire terminal and auto-refreshes every 2 seconds.

## Dashboard Sections

### Header

Shows auto-mode status and elapsed time:

```
╭────────────────────────────────────────────────────────────╮
│  GSD  ● AUTO                                      1h 23m   │
```

**Status indicators:**
- `● AUTO` — Auto-mode running (pulsing dot)
- `⏸ PAUSED` — Auto-mode paused (press `/gsd auto` to resume)
- `idle` — Auto-mode not running

### Current Unit

Displays the unit currently executing:

```
Now: Execute M001/S02/T04                            2m 14s
```

Includes:
- Unit type and ID
- Time elapsed since unit started

### Milestone Overview

Shows the active milestone title and progress bars:

```
M001: Payment Integrations

Tasks     ████████████████░░░░░░░░   75%   6/8 tasks
Slices    ████████░░░░░░░░░░░░░░░░   33%   2/6 slices
Milestones████░░░░░░░░░░░░░░░░░░░░   20%   1/5 milestones
```

**Progress metrics:**
- **Tasks** — Only shown for the active slice (task-level granularity)
- **Slices** — Roadmap completion for the current milestone
- **Milestones** — Overall project completion

### Slice Breakdown

Lists all slices in the active milestone with their completion status:

```
  ✓ S01: Core Types and File I/O              low
  ▸ S02: State Derivation                     medium
    • T01: Parse roadmap and plan files
    • T02: Derive phase from state
    ▸ T03: Build milestone registry
    • T04: Write tests
  ○ S03: Auto-Mode State Machine              high
  ○ S04: Crash Recovery                       medium
```

**Icons:**
- `✓` — Slice complete (merged to main)
- `▸` — Slice active (currently working)
- `○` — Slice pending (not started)
- `•` — Task not started
- `▸` — Task active (currently executing)
- `✓` — Task complete

**Risk levels:**
- `low` — Routine work, well-understood
- `medium` — Some unknowns, moderate complexity
- `high` — Significant unknowns, high complexity

### Completed Units

Shows the 10 most recently completed units:

```

  ✓ Execute M001/S01/T04                               2m 18s
  ✓ Complete M001/S01                                  4m 56s
  ✓ Reassess M001/S01                                  1m 32s
  ...and 23 more
```

Each entry shows:
- Unit type and ID
- Time taken to complete

### Cost & Usage

Tracks cumulative costs and token usage across all units:

```
─────────────────────────────────────────────────────────────
Cost & Usage

$2.347 total · 1.2M tokens · 187 tools · 45 units
in: 856k  out: 234k  cache-r: 98k  cache-w: 12k
```

**Metrics explained:**
- **total** — Cumulative cost in USD for all units in the current auto-mode session
- **tokens** — Total tokens (input + output + cache reads/writes)
- **tools** — Total tool calls across all units
- **units** — Number of units completed

**Token breakdown:**
- **in** — Input tokens sent to the model
- **out** — Output tokens generated by the model
- **cache-r** — Prompt cache read tokens (near-zero cost)
- **cache-w** — Prompt cache write tokens (standard input pricing)

Estimates remaining cost based on slice averages:

Helps estimate costs for similar projects.

## Dashboard Implementation

### Overlay Component

The dashboard is implemented as a full-screen overlay component:

```typescript src/resources/extensions/gsd/dashboard-overlay.ts
export class GSDDashboardOverlay {
  private tui: { requestRender: () => void }
  private theme: Theme
  private onClose: () => void
  private refreshTimer: ReturnType<typeof setInterval>
  private scrollOffset = 0
  private dashData: AutoDashboardData
  private milestoneData: MilestoneView | null = null

  constructor(
    tui: { requestRender: () => void },
    theme: Theme,
    onClose: () => void,
  ) {
    this.tui = tui
    this.theme = theme
    this.onClose = onClose
    this.dashData = getAutoDashboardData()

    // Load milestone data asynchronously
    this.loadData().then(() => {
      this.loading = false
      this.invalidate()
      this.tui.requestRender()
    })

    // Auto-refresh every 2 seconds
    this.refreshTimer = setInterval(() => {
      this.dashData = getAutoDashboardData()
      this.loadData().then(() => {
        this.invalidate()
        this.tui.requestRender()
      })
    }, 2000)
  }

  handleInput(data: string): void {
    if (matchesKey(data, Key.escape) || matchesKey(data, Key.ctrlAlt("g"))) {
      clearInterval(this.refreshTimer)
      this.onClose()
      return
    }

    // Scroll with arrow keys or j/k
    if (matchesKey(data, Key.down) || matchesKey(data, "j")) {
      this.scrollOffset++
      this.invalidate()
      this.tui.requestRender()
    }
  }

  render(width: number): string[] {
    const content = this.buildContentLines(width)
    const visibleContent = content.slice(
      this.scrollOffset, 
      this.scrollOffset + visibleContentRows
    )
    return this.wrapInBox(visibleContent, width)
  }
}
```

### Data Flow

The dashboard reads data from multiple sources:

```typescript
export interface AutoDashboardData {
  active: boolean
  paused: boolean
  stepMode: boolean
  startTime: number
  elapsed: number
  currentUnit: { type: string; id: string; startedAt: number } | null
  completedUnits: { type: string; id: string; startedAt: number; finishedAt: number }[]
  basePath: string
  totalCost: number
  totalTokens: number
}

export function getAutoDashboardData(): AutoDashboardData {
  const ledger = getLedger()
  const totals = ledger ? getProjectTotals(ledger.units) : null
  return {
    active,
    paused,
    stepMode,
    startTime: autoStartTime,
    elapsed: (active || paused) ? Date.now() - autoStartTime : 0,
    currentUnit: currentUnit ? { ...currentUnit } : null,
    completedUnits: [...completedUnits],
    basePath,
    totalCost: totals?.cost ?? 0,
    totalTokens: totals?.tokens.total ?? 0,
  }
}
```

**Data sources:**
- **Auto-mode state** — From `auto.ts` module-level variables
- **Metrics ledger** — From `.gsd/metrics-ledger.json` loaded by `metrics.ts`
- **Milestone data** — Derived by calling `deriveState()` and parsing roadmap/plan files

### Metrics Ledger

Cost tracking is persisted to `.gsd/metrics-ledger.json`:

```json
{
  "version": 1,
  "basePath": "/home/user/projects/my-app",
  "units": [
    {
      "unitType": "execute-task",
      "unitId": "M001/S01/T03",
      "startedAt": "2026-03-13T10:23:45.123Z",
      "finishedAt": "2026-03-13T10:27:12.456Z",
      "model": "claude-opus-4-6",
      "tokens": {
        "input": 12543,
        "output": 3421,
        "cacheRead": 8765,
        "cacheWrite": 1234,
        "total": 25963
      },
      "cost": 0.0234,
      "toolCalls": 12
    }
  ]
}
```

The ledger is updated after each unit completes:

```typescript src/resources/extensions/gsd/metrics.ts
export function snapshotUnitMetrics(
  ctx: ExtensionContext,
  unitType: string,
  unitId: string,
  startedAt: number,
  modelId: string,
): void {
  let totalInput = 0, totalOutput = 0
  let totalCacheRead = 0, totalCacheWrite = 0
  let toolCallCount = 0

  for (const entry of ctx.sessionManager.getEntries()) {
    if (entry.type === "message" && (entry as any).message?.role === "assistant") {
      const u = (entry as any).message.usage
      if (u) {
        totalInput += u.input || 0
        totalOutput += u.output || 0
        totalCacheRead += u.cacheRead || 0
        totalCacheWrite += u.cacheWrite || 0
      }
    }
    if (entry.type === "toolCall") {
      toolCallCount++
    }
  }

  const cost = calculateCost(modelId, {
    input: totalInput,
    output: totalOutput,
    cacheRead: totalCacheRead,
    cacheWrite: totalCacheWrite,
  })

  const unit: UnitMetrics = {
    unitType,
    unitId,
    startedAt: new Date(startedAt).toISOString(),
    finishedAt: new Date().toISOString(),
    model: modelId,
    tokens: {
      input: totalInput,
      output: totalOutput,
      cacheRead: totalCacheRead,
      cacheWrite: totalCacheWrite,
      total: totalInput + totalOutput + totalCacheRead + totalCacheWrite,
    },
    cost,
    toolCalls: toolCallCount,
  }

  const ledger = getLedger()
  if (ledger) {
    ledger.units.push(unit)
    saveLedger(ledger)
  }
}
```

## Navigation

**Keyboard shortcuts:**
- `↑`/`k` — Scroll up
- `↓`/`j` — Scroll down
- `g` — Jump to top
- `G` — Jump to bottom
- `Esc` — Close dashboard
- `Ctrl+Alt+G` — Toggle dashboard

## Integration with Auto-Mode

The dashboard can be opened at any time without disrupting auto-mode:

```typescript src/resources/extensions/gsd/commands.ts
context.registerCommand({
  id: "gsd.status",
  async handler(ctx) {
    const { showDashboard } = await import("./dashboard-command.js")
    await showDashboard(ctx)
  },
})
```

The overlay runs on a separate render loop and doesn't interfere with agent execution.

## Budget Ceiling

Configure a budget ceiling in `.gsd/PREFERENCES.md`:

```yaml
budget_ceiling: 5.00
```

Auto-mode will pause when the ceiling is reached:

```
Budget ceiling $5.00 reached (spent $5.12). Pausing auto-mode — /gsd auto to continue.
```

The dashboard shows a warning when projected total exceeds the ceiling:

```
Projection: 3 slices remaining
  Est. total: $5.67
  Ceiling: $5.00 (113% — will exceed ceiling)
```
